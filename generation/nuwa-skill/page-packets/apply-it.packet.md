# apply-it.packet

**Page job:** 给读者一套写自己 skill 的起手动作。

**Reader state:** 已看完整本手册，准备把女娲的形状偷到自己的 skill 里。

**Voice:** 实用清单。每条指向可执行动作，不写励志。

**Inputs:** pattern cards、design choices、running example。

**Must include:** checklist（≥ 8 条，每条指向具体动作）、starterPrompt（可直接复用的 prompt 段）、nextSteps.author（4-5 条作者维护动作）、nextSteps.thief（4-5 条偷招动作）。

**Must avoid:** "持续迭代""保持高质量"这种空话；把流程名复述一遍当 checklist。

**Packet output:** `handbook.applyIt`。

**Self-check:** checklist 每条都能在 30 分钟内开始做。

**Voice gate:** 扫 summary、checklist 首尾两项、starterPrompt 开头。
