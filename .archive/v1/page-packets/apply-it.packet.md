# apply-it.packet

**Page job:** 给读者一套写自己 skill 的起手动作。

**Reader state:** 已看完整个手册，准备把女娲的形状偷到自己的 skill。

**Voice:** 实用清单。每条都指向一个可执行动作，不写励志。

**Inputs:** pattern cards, design choices, running example.

**Must include:** checklist、starterPrompt、author next steps、thief next steps。

**Must avoid:** “持续迭代”“保持高质量”这种空话。

**Packet output:** `handbook.applyIt`.

**Self-check:** checklist 里的每项都能在 30 分钟内开始做。

**Voice gate:** 扫 `summary`、checklist 首尾项、starter prompt 开头。
