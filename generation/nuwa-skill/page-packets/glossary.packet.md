# glossary.packet

**Page job:** 把核心术语解释成读者能回到 walkthrough 里使用的概念卡。

**Reader state:** 已经见过这些词，但可能只知道名字。

**Voice:** 慢、精确、例子先于定义。每条卡说"我作为 AI 怎么用它"。

**Inputs:** brief 的 terms 表 + walkthrough stage ID。

**Must include:** 10 个 term（direct-path / diagnostic-path / local-material-mode / six-research-files / triple-validation / mental-model / heuristic / expression-dna / agentic-protocol / honest-boundary）。每条 5 字段：definition / whereItAppears / solvedProblem / howToUse / commonMisread。

**Must avoid:** 把 glossary 写成目录页；用"调研材料"替代真实值（如"塔勒布的反脆弱偏好"）。

**Packet output:** `handbook.glossary`。

**Self-check:** 每条 term 都给出具体例子，例如"塔勒布把'专家预测失败次数'当 Step 2 必查项"。

**Voice gate:** 扫每个 term 的 definition 和 commonMisread。
