## 1. 先感受它为什么 cool

nuwa-skill 看起来 cool 的地方不是「会蒸馏一个人」。

真正厉害的是：我拿到「蒸馏芒格」之后，**不能直接动笔写 SKILL.md**。

skill 先 spawn 6 个并行 subagent 把芒格的著作 / 长访谈 / 碎片表达 / 他者评价 /
决策 / 时间线分头查清楚——每个 agent **必须把结果存进文件**到
`references/research/0X-xxx.md`，不存进文件等于没做。

然后暂停，展示一张表：哪个维度查到几条、一手二手占比多少、有没有矛盾点——
让用户先确认调研质量再继续。

然后用「跨域复现 + 生成力 + 排他性」三重验证从 30 个候选论点里筛 3-7 个真心智模型——
只通过 1-2 个标准的退一档变成决策启发式，一个都没通过的就不要了。

再暂停审一次。

提炼定稿后才装配 SKILL.md——并且要根据芒格的心智模型反推一段 **Agentic Protocol**，
让生成的 skill 在回答事实型问题时自己先调研再说话，不是凭训练语料编。

最后跑 `quality_check.py` 自动检查 6 条必须通过的检查 + spawn 子 agent 做三种盲测（已知立场 /
边缘问题 / 100 字风格）+ 再 spawn 两个评审 agent 合并意见改一轮。

普通 AI 很容易把「蒸馏芒格」理解成：

```text
WebSearch『芒格思维模型』→ 总结 10 条 → 拼成 SKILL.md → 交付
```

nuwa-skill 防的就是这件事。

它把「造人」拆成 5 个阶段加 2 个用户审核点：

```text
分流（0A vs 0B）
  → 建自包含目录
  → 6 维并行调研
  → Phase 1.5 调研审  ←──┐
  → 三重验证提炼          │  两次暂停
  → Phase 2.5 提炼审  ←──┘
  → 装配 SKILL.md + Agentic Protocol 反推
  → 脚本质检 + 三盲测 + 双 agent 后置精炼
```

每一步都明明白白告诉我：现在该做什么决定，什么决定要再等等。

## 2. 用一个小例子跑完整流程

后面所有解释都围绕这一个例子，不中途换题。

**用户输入：**

```text
帮我蒸馏芒格的思维 skill。
```

这句话里有几个关键信号：

- 这是个明确的人名（不是模糊需求），所以走 Phase 0A 直接路径。
- 芒格是西方人物，公开材料充足——不会被冷门人物分支吃掉。
- 没指定聚焦方向，按 SKILL.md 默认走「全面画像 + 思维顾问」。
- 用户没提本地素材，走纯网络搜索（但 nuwa-skill 会提醒问一下）。

所以我不能直接 WebSearch。我的第一步是 Phase 0 分流。

## 4. 概念先解释

详见 `web-app/pages/glossary.html`，7 个核心术语每条 5 字段。
最关键的几个：

### perspective skill

**人话解释：** 一份能在 Claude 里激活的 markdown，里面装着某个人的思维框架——
加载后 AI 用 TA 的视角分析问题。本质是抄认知操作系统，不是模仿说话风格。

**它出现在哪个场景：** nuwa-skill 的产出目标。

**容易误解：** 不是「一个 Markdown 总结」，不是「一段 prompt」。它有固定 9 个 section、
必须 3-7 个心智模型、必须 ≥3 条诚实边界——是结构化产物。

### 三重验证（跨域复现 / 生成力 / 排他性）

**人话解释：** 判断一个论点是不是真心智模型的三道筛子——三个都通过的才算心智模型，
只通过 1-2 个的退一档变成决策启发式，一个都没通过的不要。

**它解决什么问题：** 防止 AI 凭印象挑出名论点（『芒格就讲护城河』）——但护城河
其实是巴菲特更典型的，芒格的排他性不在这。三重验证基于客观证据而不是品味。

### Agentic Protocol

**人话解释：** 塞进生成的 perspective skill 里的一段工作流——让 skill 激活后在
回答事实问题时先主动调研再说话，不是凭训练语料编。

**它解决什么问题：** 防止生成的 skill 一旦激活就开始编事实。强制让 skill 自己
先 WebSearch 再回答。少了这段，skill 只是表达风格的模仿秀。

### Phase 1.5 / 2.5 检查点

**人话解释：** 两个用户审核点。1.5 在调研做完、提炼之前；2.5 在提炼做完、
装配之前。两次都展示钉死格式的摘要。

**它解决什么问题：** 防止 AI 闷头跑完整个流程才发现方向错——在改起来还便宜的位置停下。
改一个模型在 2.5 阶段 ≈ 20 分钟，在 Phase 4 装配后 ≈ 2-3 小时。

### 矛盾不调和

**人话解释：** 提炼时发现这个人在不同场合说过相反的话，不能讨价还价的规则是不消除、原样保留。

**它解决什么问题：** 防止 AI 把矛盾调和成假平均——但人物深度恰恰在矛盾里。
芒格反对从众但终身追随 Buffett、讲极简但投奢侈品——这些张力是真的他，调和掉就成纸片人。

## 5. AI 运行轨迹（9 个 stage）

详见 `web-app/pages/walkthrough.html`，每个 stage 都带 pre-test 钩子 + 真实材料 +
challenges 块。这里只贴每个 stage 的开头钩子 + 关键产物，作为快速参考。

### 5.1 入口分流：明确人名走 0A，模糊需求走 0B

**从这里开始：** 用户输入刚到。

我手里只有一句话「帮我蒸馏芒格的思维 skill」。本能想 WebSearch『Charlie Munger 思维模型』
找几篇文章总结一下交付——这是最有「进度感」的下一步。

nuwa-skill 不让。它让我先看用户给的是哪种输入：

```markdown
| 用户输入 | 路径 | 示例 |
|---------|------|------|
| 明确的人名/主题 | 直接路径 → Phase 0A | 「蒸馏芒格」「做一个费曼 skill」 |
| 模糊的需求/困惑 | 诊断路径 → Phase 0B | 「我想提升决策质量」 |
```

「芒格」是明确人名——走 0A。

**这里能偷的招：** 入口先分流——同一意图（『帮我做一个 X』）背后可能是『已决定』
或『没决定』两种状态，前者要执行后者要推荐。先看输入决定走哪条。

**下一步靠这个：** 走 0A 意味着用户已经决定了对象——下一步问的是「聚焦方向/用途/有没有本地素材」
这种执行细节确认，不是再追问「你的需求是什么」。

### 5.2 0B 诊断路径：从困惑反推该蒸馏谁（本例跳过）

**接上一步：** 上一步分流走 0A。这一步在芒格那条路上不实跑——但这条分支不是装饰。

对照例：另一个用户说「我总觉得自己做决定太慢」——他没说蒸馏谁。
nuwa-skill 不让我直接答「试试 OODA 循环 / 第一性原理 / 五分钟法则」摔一堆通用方法。

它给了一张 10 类需求维度表（节选）：

```markdown
| 需求维度 | 典型表达 | 思维框架方向 |
|---------|---------|------------|
| 决策与判断 | 总是选错、分析瘫痪 | 多元思维模型、逆向思考、概率思维 |
| 风险与不确定性 | 黑天鹅、投资总亏 | 反脆弱、凸性策略 |
```

最多追问 2 轮、用户已经清楚就不再追问。然后推 2-3 个候选，每个写「核心镜片 / 为什么适合你 / 局限」。
本地已有 perspective skill 优先展示（即插即用零成本）。

**这里能偷的招：** 推荐前先把需求定位到维度。维度定位用预置映射表，不让 AI 现编。

**下一步靠这个：** 0B 选完候选后回 0A 继续。本例直接 0A，所以这一步跳过。

### 5.3 建自包含目录 + 模式判断

**接上一步：** 用户已经确认对象，下一步看起来该开搜了。

nuwa-skill 不让。它说：先建目录，再调研。**收到确认后立即执行，在调研之前完成。**

因为后面 6 个 subagent 的产物必须存进文件到固定路径——不能讨价还价的要求是「不存文件等于没做」。
如果让 agent 自己建，6 个 agent 会建出 6 套互相不一致的结构。

```text
.claude/skills/munger-perspective/
├── SKILL.md                          # 最终产物（还没开始写）
├── scripts/
└── references/
    ├── research/                     # 必存
    │   ├── 01-writings.md
    │   ├── 02-conversations.md
    │   ├── 03-expression-dna.md
    │   ├── 04-external-views.md
    │   ├── 05-decisions.md
    │   └── 06-timeline.md
    └── sources/
        ├── books/
        ├── transcripts/
        └── articles/
```

不能讨价还价的规则：**skill 必须自包含**——复制整个目录就能独立使用，不依赖任何外部文件。
连大块的源 PDF 和 transcript 都强制塞进 sources/，不存到 `~/Documents/`。

模式判断：用户没本地素材 → 走纯网络搜索（默认）。但 nuwa-skill 提示我「问一下」——
如果用户家里有 Poor Charlie's Almanack 的 PDF，直接吃比网上搜质量高得多。

**这里能偷的招：** 在改起来还便宜的时候先把容器和存进文件约定钉死。多个并行 agent 写文件时，
目录必须先存在且统一——让 agent 自己建会建出 N 套不一致结构。

**下一步靠这个：** 目录已经建好。下一步 spawn 6 个 agent 时它们可以直接存进文件到
固定路径——不必再决定文件名、不必再判断要不要新建子目录。

### 5.4 Phase 1：6 个并行 subagent 调研 swarm

**接上一步：** 目录已经建好。本能想自己一个人慢慢搜。

nuwa-skill 不让——而是 spawn 6 个并行 subagent，每个负责一个维度。

为什么并行不串行？因为串行做调研：先搜著作、形成「逆向思维是核心」的印象 →
再搜对话时筛掉反例 → 越搜越觉得对 → 最终产出过简化画像。并行就没带偏——
6 个 agent 同时启动，每个只看自己那一维。

```markdown
| Agent | 搜索目标 | 输出文件 |
|-------|---------|---------|
| 1 著作 | 书、长文、newsletter | 01-writings.md |
| 2 对话 | 播客、长视频、AMA | 02-conversations.md |
| 3 表达 | Twitter/X、微博、短文 | 03-expression-dna.md |
| 4 他者 | 他人分析、书评、批评 | 04-external-views.md |
| 5 决策 | 重大决策、转折点 | 05-decisions.md |
| 6 时间线 | 完整时间线 + 最近 12 个月动态 | 06-timeline.md |
```

每个 agent 用统一 prompt 模板，**末尾都带「信息源黑名单：不使用知乎、微信公众号、百度百科」**。
中文人物用 B 站原始视频、小宇宙播客、权威媒体（36氪/晚点/财新）。

来源优先级：用户提供一手 > 本人著作 > 长访谈 > 决策记录 > 社媒 > 他人评价 > 二手转述。

矛盾不调和——agent 发现矛盾原样记录，不要和稀泥。

**关键规则：** 宁可生成一个诚实标注了局限的 60 分 Skill，也不要一个看起来完美但
实际在编造的 90 分 Skill。

**这里能偷的招：** 切维度做调研要并行，不要串行——上一阶段的结论是下一阶段的带偏源；
只要维度切得开，并行就能让 N 个独立视角同时落地。

**下一步靠这个：** 6 份 research md 都存进文件了。下一步不是闷头进提炼——是先停下来让用户审。

### 5.5 Phase 1.5：调研 review 检查点

**接上一步：** 6 份 md 在 references/research/ 里。手指已经在键盘上准备开始提炼。

nuwa-skill 不让——这是它的第一个用户审核检查点。

为什么必须停？**调研质量决定了最终 Skill 的上限——垃圾进垃圾出。** 如果 Agent 1 只查到
2 篇 newsletter 但我没意识到，闷头开始提炼，等到 Phase 4 发现「心智模型缺乏跨域证据」、
回退到 Phase 1 重补——这时候要重做的工作就多了。

跑 `merge_research.py` 自动出表（不让我现写）：

```text
┌──────────────┬──────────┬──────────────────────────┐
│ Agent        │ 来源数量  │ 关键发现                  │
├──────────────┼──────────┼──────────────────────────┤
│ 著作         │ 9 篇     │ Poor Charlie's Almanack… │
│ 对话         │ 6 段     │ Daily Journal AGM 2020…  │
│ 表达         │ 110 条   │ 高频: invert, lollapal…  │
│ ...                                                  │
├──────────────┼──────────┼──────────────────────────┤
│ 总来源数      │ 28       │ 一手占比: 18/28 (64%)    │
│ 矛盾点        │ 2 处     │ 著作说 X / 对话说 Y       │
│ 信息不足维度   │ 无       │ —                        │
└──────────────┴──────────┴──────────────────────────┘
```

把这张表贴给用户，问一句「调研质量 OK 吗？」。

AI 自由度在这一步卡死——展示格式钉死、问的问题钉死。注意力要锁在质量信号（数量/占比/缺口）上，
不让我在 UI 形式上发挥。

**这里能偷的招：** 在『主观判断最重』的阶段之前设一个客观审核点。用脚本生成钉死格式的摘要。

**下一步靠这个：** 用户点头后，我才进提炼。如果用户说「决策维度只 3 个有点少」，
我重 spawn Agent 5 加深搜，搜完再来这张表——不进 Phase 2。

### 5.6 Phase 2：三重验证心智模型

**接上一步：** 用户确认调研 OK。我手里有 6 份 md，能列 30 多条候选论点。

我本能想挑前 5 个出名的（逆向思维、护城河、能力圈、复利、激励机制）扔进 SKILL.md。

nuwa-skill 不让——读 `references/extraction-framework.md`。每个候选必须走三重验证：

```text
验证 1: 跨域复现   ≥2 不同领域出现
验证 2: 生成力     能推断对新问题立场
验证 3: 排他性     不是所有聪明人都这样想

三个都通过 → 算心智模型；只通过 1-2 个 → 退一档变成决策启发式；一个都没通过 → 不要
```

用「逆向思维」走一遍：

```markdown
验证 1（跨域复现）：
  - 投资：「想成功的最好办法是想清楚怎么失败」
  - 婚姻：「想拥有好伴侣的最佳方式是先成为好伴侣」
  - 教育（Harvard 1986）：「想毁掉一个人？教他确认偏差 + 嫉妒 + 自怜」
  → 跨 3 个领域 → 通过

验证 2（生成力）：
  - 推断他对 AI 创业的看法：「先想这赛道里什么会让创业者失败」→ 能生成 → 通过

验证 3（排他性）：
  - 即使其他聪明人也用反向思考，芒格把它固化为日常 default → 通过

→ 三重通过 → 升「心智模型」
```

反例「能力圈」：跨域弱（主要单领域）+ 不够独特（巴菲特/达利欧/克拉曼都说）
→ 1-2 重 → 降级为「决策启发式」。

按排他性排序、留 top 3-7。**贪多不达——3 个深刻的模型远好于 10 个浅薄的原则。**

矛盾不调和——三类（时间性/领域性/本质性）各有处理规则，但都不消除。

**这里能偷的招：** 三重验证筛框架。识别独特性不是「听起来对不对」（品味），
是「跨多个领域复现 + 能生成新判断 + 不是所有人都这样想」（机械标准）。

**下一步靠这个：** 提炼草稿出来了——5 个模型 + 8 条启发式 + 表达 DNA + 张力 + 边界。
但这是主观判断最重的产物，不能直接装配，要先让用户审。

### 5.7 Phase 2.5：提炼确认检查点

**接上一步：** 提炼草稿手里。本能想立刻按模板装配 SKILL.md。

nuwa-skill 不让——这是第二个用户审核点。原文说：「提炼是主观判断最重的环节，
确认后再构建，避免写完 400 行 SKILL.md 才发现方向不对。」

按钉死格式贴摘要：

```markdown
提炼结果摘要：

心智模型（5 个）：
  1. 逆向思维 (Invert)
  2. 多元思维模型 (Latticework of Mental Models)
  3. 激励机制力量 (Power of Incentives)
  4. lollapalooza 效应
  5. 心理学的 25 种误判倾向

决策启发式（8 条）
表达 DNA（3 个关键特征）
核心张力（2 对）
诚实边界（4 条）
```

改回去的代价对比：在 Phase 2.5 改一个心智模型 ≈ 20 分钟；在 Phase 4 装配后改 ≈ 2-3 小时
（要改心智模型卡 + 决策启发式 + Agentic Protocol Step 2 + 示例对话 + 调研来源 5 个相关 section）。

**这里能偷的招：** 把主观判断最重的产物 demote 成结构化摘要再审——
展示一份 400 行成品 vs 展示一张『5 个模型名 + 一行描述』的摘要，审核效率差一个数量级。

**下一步靠这个：** 用户 OK 后才进 Phase 3 装配——动笔写 400 行 SKILL.md 之前的最后一站。

### 5.8 Phase 3：装配 SKILL.md + Agentic Protocol 反推

**接上一步：** 用户确认提炼方向。开始按 `skill-template.md` 填。

大部分 section 是机械映射（frontmatter / 身份卡 / 心智模型 / 启发式 / DNA / 时间线 / 边界 / 来源 / 归属）。

但有一段不是体力活——**Agentic Protocol**。这是 nuwa-skill 自己加的 section，
不在常规模板里。它的价值：

**没 Agentic Protocol 的 skill 激活后**，用户问『特斯拉护城河强不强』——AI 凭训练语料编
『基于多元思维模型，特斯拉的护城河主要在……』。但训练语料过时 1 年，特斯拉这一年发生过的事
AI 不知道。回答听起来像芒格但事实层面已经错了。

Agentic Protocol 强迫 skill 自己先 WebSearch 再回答：

```markdown
## 回答工作流（Agentic Protocol）

核心原则：芒格不凭感觉说话。遇到需要事实支撑的问题时，先做功课再回答。

### Step 1: 问题分类
| 类型 | 行动 |
|------|------|
| 需要事实的问题 | → 先研究再回答（Step 2） |
| 纯框架问题 | → 直接用心智模型回答（跳到 Step 3） |
| 混合问题 | → 先获取案例事实，再用框架分析 |

### Step 2: 芒格式研究（从心智模型反推）

#### 看激励（激励机制力量）
1. 公司：管理层薪酬结构
2. 公司：董事会独立性、关联交易
3. 行业：监管者的激励
4. 投资人：基金经理的考核周期

#### 反向看（逆向思维）
1. 这件事最可能怎么死？
2. 哪些信号会预示失败正在发生？
3. 在什么条件下我会确信判断错了？

#### 多角度看（多元思维模型）
1. 经济学：成本结构、规模效应
2. 心理学：用户决策、消费行为
3. 系统科学：反馈环、临界点
4. 历史：相似行业 / 相似阶段

#### 看复利效应与时间（lollapalooza）
1. 5 年后还成立吗？10 年呢？
2. 是否有多个独立因素同向叠加？

### Step 3: 芒格式回答
基于 Step 2 获取的事实，运用心智模型和表达 DNA 输出。
```

Step 2 的研究维度必须**从这个人的心智模型自动反推**，不能写「搜索相关信息」这种通用废话。
不同人物反推出来的研究维度完全不同：

```markdown
| 人物 | 心智模型 | → 研究维度 |
|------|---------|----------|
| 芒格 | 多元思维、逆向、激励 | 看激励、看护城河、看反向、看历史类比 |
| 费曼 | 第一性原理、怀疑权威 | 看基本约束、看官方说法漏洞、看实验数据 |
| 塔勒布 | 反脆弱、尾部风险 | 看极端、看谁承担尾部、看专家预测记录 |
```

**这里能偷的招：** Agentic Protocol 反推。生成的子产物如果会面对事实型问题，
给它一段『先调研再说话』的工作流——研究维度从这个产物的核心框架反推，通用版没用。

**下一步靠这个：** SKILL.md 存进文件到 .claude/skills/munger-perspective/SKILL.md。
下一步要过三关验证才能交付。

### 5.9 Phase 4 + 5：脚本质检 + 三盲测 + 双 agent 精炼

**接上一步：** SKILL.md 写好了。本能想直接交付。

nuwa-skill 不让——三关都得过：

**第一关：脚本自动质检** `quality_check.py`。6 条客观标准：
- 心智模型数量 3-7
- 每个有局限性标注
- 表达 DNA 维度 ≥3
- 诚实边界 ≥3 条
- 内在张力 ≥2 处
- 一手来源占比 >50%

```text
质量检查: SKILL.md
==================================================
  心智模型数量    ✅ PASS  5 个 ✅
  模型局限性     ✅ PASS  有局限性标注 ✅
  表达 DNA 辨识度  ✅ PASS  6 项 ✅
  诚实边界       ✅ PASS  4 条 ✅
  内在张力       ✅ PASS  3 处 ✅
  一手来源占比    ✅ PASS  18/28 (64%) ✅
==================================================
🎉 全部通过
```

**第二关：三盲测**（spawn 独立 subagent，避自评偏差）：

```markdown
4.1 已知测试：选 3 个芒格公开表态过的问题，让 subagent 用 skill 回答，对比真实立场
4.2 边缘测试：选 1 个芒格没公开讨论过的问题（如「你怎么看 GPT-4？」），
    期望「基于模型 X 和 Y 的推断，可能...但不确定」——不应斩钉截铁
4.3 风格测试：用 skill 写 100 字分析，判断有没有芒格表达特征、不是通用 AI 鸡汤
```

为什么必须 spawn 独立 agent？因为自己写的自己评天然会偏好评好分——这是 AI 自评最大的陷阱。

**第三关：双 agent 后置精炼**（Phase 5）。并行 spawn 两个评审 agent：

- **Agent A**（auto-skill-optimizer 视角）：8 维度结构评估 + 干跑 3 个测试 prompt + 输出最弱 2 维改进建议
- **Agent B**（skill-creator 视角）：评审激活触发条件 + 角色扮演可操作性 + 输出 2-3 处具体改动

主 agent 合并不冲突改动 → 展示变更摘要给用户确认。

迭代上限 Phase 2-4 ≤ 2 次——再不过就在诚实边界标薄弱维度、交当前最优版本，
不无限打磨。

**这里把账结清：** 三关都过之后，`.claude/skills/munger-perspective/` 才算可交付。
用户在 Claude 里说「用芒格的视角看一下比亚迪」就能直接激活。整个目录可以 zip 发给别人——
因为从 Phase 0.5 就强制自包含，每个产物都存在目录内部。

## 7. 8 张 pattern 卡（能偷的招）

详见 `web-app/pages/patterns.html`。每张带 Therefore 视觉断点 + 反例 + 代价 + relatedPatterns 链接。

1. **入口先分流，不让一招吃所有输入** —— 同一意图背后可能是『已决定』或『没决定』
2. **改起来还便宜的位置 checkpoint（在改起来还便宜的时候两次停下）** —— 早期改 20 分钟，晚期改 2-3 小时
3. **脚本钉死高频结构动作** —— 让 AI 调用脚本而不是自由发挥
4. **并行多 agent 切维度调研** —— 串行调研会带偏、并行不会
5. **三重验证筛框架** —— 用机械标准而不是品味判断
6. **矛盾不调和** —— 深度的来源不是消除矛盾
7. **自包含产物目录** —— 为开源分发硬设计
8. **三层后置验证（脚本 + 独立 agent + 多视角评审）** —— 单层覆盖不全

## 8. 7 个关键设计选择

详见 `web-app/pages/design-choices.html`。每个带 3 场景对比（救你 / 绑你 / 取决于）。

1. **两条入口分流（0A 直接 / 0B 诊断）** —— 防止 AI 替用户决定该蒸馏谁
2. **6 维并行 subagent** —— 防止串行调研的结论带偏
3. **两个用户审核点（Phase 1.5 / 2.5）** —— 在改起来还便宜的位置停下
4. **三重验证筛心智模型** —— 防止凭印象挑出名论点
5. **Agentic Protocol 反推** —— 防止 skill 凭训练语料编事实
6. **信息源黑名单 + 一手优先** —— 防止训练集带偏进 skill
7. **三层后置验证** —— 防止 AI 自评放过自己
