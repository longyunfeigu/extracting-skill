# overview.packet

**Page job:** 让从没看过女娲的人先看见普通 AI 把"造一个人物 skill"做坏成什么样，再看见女娲把它拆成路由 → 自包含包 → 多维取证 → 三道筛选 → 模板组装 → 三种验证 → 双视角精炼。

**Reader state:** 读者可能听过 Claude/Codex skill，但不知道女娲为什么不直接写 role-play prompt。

**Voice:** 教科书章节。先让读者亲眼看见失败，再命名女娲的做法。术语第一次出现必须就地解释。

**Inputs:** `handbook-brief.md` 的 total task / running example / 三个 perspective skill 对比（taleb / munger / mrbeast）。

**Must include:** opening scene（AI 直接写 50 行 role-play 的失败片段）；predict prompt；primer 5-7 拍 + orientation 图；wow（3 个 perspective 的 Agentic Protocol 对照表/图）；4-5 张 bad-result before/after 卡；贯穿例子；chapterLogic。

**Must avoid:** 目录式介绍；把女娲写成"自动生成 prompt"；只赞美不展示失败。

**Packet output:** `handbook.overview`, `handbook.example`, `handbook.diagrams` 中 orientation-map + persona-compare 两条元数据。

**Self-check:** 读完 overview 能用 3-5 句话讲清"先找证据、再三道筛选、再模板组装、再三种验证"。

**Voice gate:** 扫 openingScene 收尾、wowMoment、每张 badResults 卡。
