# walkthrough.packet

**Page job:** Show how I, the agent, move through Nuwa stage by stage.

**Reader state:** The reader has seen the overview and wants to know what happens when the request arrives.

**Voice:** First-person execution voice. Use "我" for auditable actions, not hidden thoughts.

**Page-specific standard:** Every stage shows input, action, output, blocked shortcut, pain caught, freedom level, and handoff.

**Evidence shape:** Jobs request, directory tree, file names, command snippets, generated section excerpts.

**Failure mode:** A checklist with no scene and no real artifact.

**Pain scan rows used:** Saved research files, checkpoints, synthesis subjectivity, current-facts protocol, validation.

**Mechanism threads:** Evidence thread, synthesis thread, boundary thread, current-facts thread.

**Inputs:** Brief stages, `SKILL.md` phases, scripts, template, Jobs example.

**Must include:** Pre-test hooks, quick reference metadata, reusable move, reader challenges.

**Must avoid:** "我作为 AI" repetition, unexplained jargon, private hidden thought.

**Packet output:** `handbook.walkthrough[]`.

**Self-check:** The next stage depends on the previous stage's output.
