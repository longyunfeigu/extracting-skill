# patterns.packet

**Page job:** 把女娲的设计动作抽成能搬到其他 skill 的 pattern card。

**Reader state:** 读者想偷招，不一定想照搬女娲。

**Voice:** 紧凑、可复用、有成本。problem 和 solution 之间要有 `therefore` 断点。

**Inputs:** pattern IDs and links from brief, `cards-patterns.md`.

**Must include:** 7 cards；每张有 `therefore` 和 `relatedPatterns`。

**Must avoid:** 把源 skill 的章节标题改名成 pattern；所有 pattern 都说“适用于复杂任务”。

**Packet output:** `handbook.patterns` and `pattern-network` diagram.

**Self-check:** 每个 pattern 至少连到 1 个其它 pattern，relation 说明关系类型。

**Voice gate:** 扫每张卡的 `prevents`、`therefore`、`antiExample`。
