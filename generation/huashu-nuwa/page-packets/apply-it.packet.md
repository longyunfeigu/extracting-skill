# apply-it.packet

**Page job:** Help the reader write a similar skill from Nuwa's shape.

**Reader state:** The reader has seen examples and wants a starting checklist.

**Voice:** Practical. Short steps, concrete prompts, no motivation speech.

**Evidence shape:** Checklist, starter prompt, next steps for maintainers and pattern thieves.

**Failure mode:** Generic advice about "be rigorous".

**Pain scan rows used:** Examples copied without reasons, generated output treated as rules, missing boundaries.

**Inputs:** Extracted patterns and design choices.

**Must include:** A copy-paste starter prompt that begins from bad AI behavior.

**Must avoid:** Asking the reader to build the whole Nuwa pipeline by default.

**Packet output:** `handbook.applyIt`.

**Self-check:** The first five checklist items could be used before writing a new skill.
