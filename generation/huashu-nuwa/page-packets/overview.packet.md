# overview.packet

**Page job:** Show ordinary AI failure first, then reveal Nuwa's high-level map.

**Reader state:** The reader may know "person skill" as roleplay, but not as a research-to-skill pipeline.

**Voice:** Concrete teacher. Start with a visible bad result, then show the mechanism.

**Evidence shape:** Opening scene, predict prompt, primer beats, flow diagram, Agentic Protocol comparison, before/after cards, running example.

**Failure mode:** Abstract praise such as "Nuwa is powerful" without showing what it prevents.

**Pain scan rows used:** Voice imitation, unranked sources, current-facts failures, examples copied without reasons.

**Inputs:** `handbook-brief.md`, `SKILL.md`, `references/extraction-framework.md`, `examples/steve-jobs-perspective/SKILL.md`.

**Must include:** Default behavior versus skill-shaped behavior, one running Jobs example, chapter logic.

**Must avoid:** Directory listing, source terms before explanation, table-of-contents-only overview.

**Packet output:** `handbook.overview`, `handbook.example`, and diagrams `main-flow`, `agentic-compare`.

**Self-check:** A new reader can say what Nuwa does in 3-5 sentences.
