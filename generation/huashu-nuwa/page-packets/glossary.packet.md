# glossary.packet

**Page job:** Explain design-heavy terms through concrete values from Nuwa.

**Reader state:** The reader may have seen the terms in Walkthrough, but wants stable definitions.

**Voice:** Plain Chinese. Each card should answer how the agent uses the term.

**Evidence shape:** Term, definition, stage, solved problem, use, common misread.

**Failure mode:** Isolated dictionary that repeats source-skill wording.

**Pain scan rows used:** Voice imitation, synthesis subjectivity, current facts, self-contained package.

**Inputs:** `references/extraction-framework.md`, `SKILL.md`, generated examples.

**Must include:** Mental model, decision heuristic, expression DNA, honest boundary, Agentic Protocol, six-road research.

**Must avoid:** Explaining jargon with jargon.

**Packet output:** `handbook.glossary[]`.

**Self-check:** A term card gives a concrete example value from Nuwa.
